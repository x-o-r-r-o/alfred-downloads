# Downloads

Browse, open, reveal, drag and clean up ~/Downloads, newest first.

> **Status:** planned — not yet functional. See [PLAN.md](PLAN.md).

## Usage

Browse, open, reveal, drag and clean up ~/Downloads, newest first via the `dls` keyword.

![Downloads results in Alfred](images/dls.png)

* <kbd>↩</kbd> Primary action.
* <kbd>⌘</kbd><kbd>↩</kbd> Secondary action.
* <kbd>⌘</kbd><kbd>Y</kbd> Quick Look.

Every keyword can be changed in the Workflow’s Configuration.

## Development

```bash
./build.sh   # -> dist/alfred-downloads-<version>.alfredworkflow
```
